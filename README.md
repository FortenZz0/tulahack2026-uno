# Exoplanet Worker

Cloudflare Worker для доступа к NASA Exoplanet Archive API.

## Наш принцип

Кол-во запросов к NASA API ограничено. Воркер обращается к NASA каждые 10 минут. 
Даже если с клиента придет запрос на обновление, воркер не станет запрашивать данные из NASA - он возьмет из своего кеша прошлый ответ NASA.
