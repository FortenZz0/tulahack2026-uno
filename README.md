# Exoplanet Worker

Cloudflare Worker для доступа к NASA Exoplanet Archive API.

## Наш принцип

Кол-во запросов к NASA API ограничено. Воркер обращается к NASA каждые 10 минут. 
Даже если с клиента придет запрос на обновление, воркер не станет запрашивать данные из NASA - он возьмет из своего кеша прошлый ответ NASA.

## Как запустить

### Требования
* Node.js 22.15+ (или 24+) + npm

### Первичная настройка
> npm ci

### Публикация
Сохраните ключ AITUNNEL в Cloudflare Secret `AI_TOKEN`:

> npx wrangler secret put AI_TOKEN

> npx wrangler deploy

Используется модель `deepseek-v4.1-flash-1017` через
[`POST https://api.aitunnel.ru/v1/chat/completions`](https://aitunnel.ru/models/deepseek-v4-1-flash-1017).
Для локального запуска укажите `AI_TOKEN` в окружении Wrangler, например в `.dev.vars`.

## API

* `GET /planets` — каталог планет.
* `GET /stars` — каталог звёзд.
* `GET /full` — оба каталога.
* `GET /preview` — до 50 планет с наибольшим `esi.simple` и только связанные с ними звёзды.
  Планеты без рассчитанного ESI исключаются. Описания при этом не генерируются.
* `GET /desc?id=planet%3Atest%200` — описание планеты. Передавайте точный `id` из каталога
  через `URLSearchParams` или `encodeURIComponent`.

Ответ `/desc`:

```json
{ "id": "planet:test 0", "description": "Описание планеты на русском языке..." }
```

Без `id` возвращается `400`, для неизвестной планеты — `404`, при сбое генерации или KV — `503`.

При первом `/desc` создаются описания планеты и её родительской звезды по отдельности.
В `PLANETS_KV` это две разные записи: `descriptions:planet:<имя>` и `descriptions:star:<имя>`.
У нескольких планет одной звезды используется одно описание звезды. Если данные звезды отсутствуют,
генерируется только описание планеты. API возвращает описание планеты.

Описания сохраняются без TTL и не перезаписываются при обновлении NASA.
Повторный `/desc` читает KV без обращения к AI или NASA.
Durable Object `DescriptionGenerator` на каждый id объединяет одновременные запросы
и сохраняет результат генерации перед публикацией в KV. Это предотвращает повторную генерацию
при задержке распространения KV или сбое его записи. Неуспешные и обрезанные ответы AI
не сохраняются; следующий запрос может повторить генерацию.

## Научная основа HASA

При разработке научных инструкций для ИИ HASA использовались следующие работы как теоретическая основа для интерпретации характеристик экзопланет и оценки их потенциальной обитаемости.

### Научные публикации

1. **Schulze-Makuch et al. (2011)** — *A Two-Tiered Approach to Assessing the Habitability of Exoplanets*.
   - Тема: индекс сходства с Землёй (ESI) и оценка потенциальной обитаемости.
   - DOI: https://doi.org/10.1089/ast.2010.0592

2. **Kopparapu et al. (2013)** — *Habitable Zones Around Main-sequence Stars: New Estimates*.
   - Тема: расчёт границ обитаемой зоны вокруг звёзд.
   - DOI: https://doi.org/10.1088/0004-637X/765/2/131

3. **Kopparapu et al. (2014)** — *Habitable Zones around Main-sequence Stars: Dependence on Planetary Mass*.
   - Тема: влияние массы планеты на границы обитаемой зоны.
   - DOI: https://doi.org/10.1088/2041-8205/787/2/L29

4. **Rogers (2015)** — *Most 1.6 Earth-Radius Planets Are Not Rocky*.
   - Тема: ограничения определения каменного состава по радиусу планеты.
   - DOI: https://doi.org/10.1088/0004-637X/801/1/41

5. **Chen & Kipping (2017)** — *Probabilistic Forecasting of the Masses and Radii of Other Worlds*.
   - Тема: вероятностные зависимости массы и радиуса экзопланет.
   - DOI: https://doi.org/10.3847/1538-4357/834/1/17

6. **Kane & Gelino (2012)** — исследование обитаемых зон на эксцентричных планетных орбитах.
   - Тема: изменение условий облучения в течение орбитального периода.
   - DOI: https://doi.org/10.1089/ast.2011.0798

7. **Haghighipour & Kaltenegger (2013)** — исследование обитаемых зон в двойных звёздных системах.
   - Тема: влияние нескольких звёзд на условия потенциальной обитаемости.
   - DOI: https://doi.org/10.1088/0004-637X/777/2/166

8. **Müller & Haghighipour (2014)** — исследование обитаемых зон в кратных звёздных системах.
   - Тема: моделирование обитаемых зон с учётом нескольких звёзд.
   - DOI: https://doi.org/10.1088/0004-637X/782/1/26

9. **Luger & Barnes (2015)** — *Extreme Water Loss and Abiotic O₂ Buildup on Planets Throughout the Habitable Zones of M Dwarfs*.
   - Тема: потеря воды, эволюция атмосферы и ограничения обитаемости планет красных карликов.
   - DOI: https://doi.org/10.1089/ast.2014.1231

10. **Armstrong et al. (2016)** — исследование звёздной активности и сверхвспышек, включая Kepler-438.
    - Тема: влияние звёздных вспышек на условия потенциальной обитаемости.
    - DOI: https://doi.org/10.1093/mnras/stv2419

### Источник астрономических данных

**NASA Exoplanet Archive**
- Официальный сайт: https://exoplanetarchive.ipac.caltech.edu/
- Используемая таблица: `pscomppars` (Planetary Systems Composite Parameters).

### Ограничения

Перечисленные публикации составляют научную основу правил интерпретации данных, но не являются доказательством обитаемости конкретных экзопланет.

Описания HASA формируются на основе каталожных параметров и научных ограничений. Индекс ESI, расположение в обитаемой зоне и равновесная температура не доказывают наличие атмосферы, жидкой воды или жизни.

Не все перечисленные публикации были независимо проверены по полному тексту. Генерация описаний не является самостоятельной проверкой научных статей.
