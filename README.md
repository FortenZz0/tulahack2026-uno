# TulaHack 2026 — UNO

Веб-приложение для исследования экзопланет и их сходства с Землёй. Проект создан для кейса № 3 «Поиск планеты, пригодной для жизни»: он объединяет данные NASA Exoplanet Archive, рейтинг ESI, интерактивные визуализации и научно-популярные описания.

## Что есть на сайте

### Рейтинг 50 планет

Слева расположен список до 50 экзопланет с наибольшим упрощённым ESI. У каждой указаны название, родительская звезда и индекс с двумя знаками после запятой. При выборе планеты справа обновляются модель, характеристики, орбита и описание.

По умолчанию открыта Земля со справочными данными и ESI = 1. Кнопка «к Земле» с вращающейся мини-моделью возвращает к ней из любой выбранной планеты.

### Интерактивная 3D-модель

Большую модель планеты можно вращать и приближать в заданных пределах. Материалы различаются по размерному классу: каменистые фактуры, облачные поверхности, полосы и вихри газовых планет. У каждой планеты собственный повторяемый рисунок.

Название, класс планеты и ссылка на её звезду находятся рядом с моделью. Ссылка раскрывает карточку и прокручивает её к разделу о звезде. На фоне работает анимированное звёздное небо.

### Раскрывающаяся карточка характеристик

Внизу показаны основные параметры: радиус, орбитальный период, поток звёздного излучения и большая полуось. Карточка раскрывается кнопкой со стрелкой, а модель планеты плавно уменьшается. Всё содержимое карточки можно прокручивать.

Внутри находятся:

- **«Почему эта планета в топе?»** — итоговый ESI, место в рейтинге и две шкалы сходства с Землёй: по радиусу и излучению. Короткое объяснение формируется из числовых параметров без ИИ.
- **Физические характеристики** — масса, радиус, плотность, гравитация, скорость убегания, равновесная температура и поток излучения. Пределы измерений и оценки отмечаются сносками.
- **Орбита** — её параметры, схема обитаемых зон и график изменения излучения, когда хватает данных.
- **Звезда** — отдельная 3D-модель, спектральный класс, температура, масса, радиус, светимость и возраст. Названия других известных планет системы открывают их карточки.
- **Описание** — нейроописание выбранной экзопланеты или готовый справочный текст о Земле.

### Орбита и обитаемая зона

Двумерная схема показывает звезду в фокусе эллипса, орбиту и планету. Консервативная обитаемая зона выделена зелёным кольцом, оптимистичная — более широким синим.

Если известен орбитальный период, доступна анимация с неравномерным движением по законам Кеплера. Ползунок времени позволяет выбрать момент в сутках; движение можно поставить на паузу. Пока схема или график видны, панель времени закрепляется внизу прокручиваемой карточки.

График показывает изменение потока энергии от звезды за оборот. Для идеально круговой орбиты он скрыт, поскольку поток в этой модели постоянен. При недостатке данных соответствующие визуализации и элементы управления не выводятся.

### Описания планет

Нейроописание объясняет известные свойства планеты, их значение для потенциальной обитаемости и ограничения наблюдений. Оно загружается при просмотре раздела. При ошибке доступен повторный запрос.

**ESI показывает сходство выбранных параметров с земными, а не вероятность существования жизни.** Обитаемая зона не доказывает наличие воды или атмосферы. Равновесная температура отличается от температуры поверхности. Материалы планет и звёзд — художественные иллюстрации, а не восстановленные изображения наблюдаемых объектов.

## Как это реализовано

### Структура репозитория

Фронтенд и Cloudflare Worker находятся в одном репозитории. Worker перенесён в `worker/` из отдельного репозитория https://github.com/FortenZz0/tulahack2026-uno-exoworker с сохранением истории коммитов. У частей проекта отдельные `package.json` и файлы зависимостей.

```text
app/
  index.html                  Страница и подключение компонентов
  main.js                     Инициализация приложения
  cmp/                        Компоненты интерфейса и их тесты
  lib/                        Клиентская библиотека каталогов
  sass/                       Общие стили и адаптивная компоновка
worker/
  src/index.js                HTTP API и обновление данных по расписанию
  src/nasa.js                 Преобразование данных NASA
  src/esi.js                  Вычисления ESI
  src/habitable-zone.js       Обитаемые зоны и доли орбитального периода
  src/multi-star.js           Модели для кратных звёздных систем
  src/ai/                    Генерация описаний и тексты инструкций
  test/                      Тесты Worker
  wrangler.jsonc             Настройки Cloudflare
context/case.txt             Условие кейса
vite.config.js               Сборка фронтенда
```

### Фронтенд

Интерфейс написан на **JavaScript с ES modules**. **Vite** запускает сервер разработки и собирает приложение; **Nunjucks** подключает HTML-компоненты. Для оформления используются **Sass**, **Bootstrap** и **Font Awesome**, для части работы с DOM — **jQuery**. 3D-модели строятся на **Three.js**, звёздный фон — на WebGL-шейдере. Схема орбиты и график излучения используют SVG.

Точка входа — [`app/main.js`](app/main.js). Здесь создаются библиотека каталогов, фон, модели, схема орбиты, блок ESI и клиент описаний. Контроллер `planet-selection` передаёт выбранную планету связанным компонентам, которые обновляют своё содержимое. Настройки звёздного неба также задаются в `main.js`.

[`ExoplanetLibrary`](app/lib/exoplanet-library.js) одновременно запрашивает `/preview` и `/full`. Интерфейс начинает работать после первого успешного ответа; полный каталог позволяет получать связанные объекты, включая другие планеты системы. Повторные попытки загрузки используют увеличивающуюся задержку.

На широком экране каталог и модель расположены рядом. На небольшом — каталог, модель и характеристики идут друг за другом. Стили учитывают сенсорное управление и настройки уменьшения движения.

### Визуализации

- **Планеты:** сферическая геометрия с процедурными текстурами. Пресет выбирается по `classification.sizeClass`, а нормализованное имя хешируется в seed генератора. Поэтому разные планеты выглядят по-разному, а одна и та же сохраняет свой вид при повторном выборе и перезагрузке.
- **Звёзды:** шейдерные материалы с палитрой по спектральному типу, грануляцией и свечением. Если тип неизвестен, для приблизительного цвета используется известная температура; при отсутствии обоих параметров — нейтральный материал.
- **Орбита:** геометрия определяется `orbit.semiMajorAxis` и `orbit.eccentricity`, границы колец приходят в `habitableZone`. Положение вычисляется из уравнения Кеплера `M = E − e·sin(E)`, поэтому движение соответствует равномерному течению времени, а не постоянной угловой скорости.
- **Излучение:** для модели одной звезды используется `S/S⊕ = (L/L☉) / r²`, где `r` — расстояние в а.е. Для кратных систем этот упрощённый график скрыт.

### Данные и расчёты на Worker

[`worker/src/index.js`](worker/src/index.js) получает данные NASA через TAP API из таблицы `pscomppars`. Парсер формирует каталоги планет и звёзд, связывает их по ID, сохраняет метаданные измерений и признаки качества.

Каталоги хранятся в **Cloudflare KV** с датой обновления. Cron `*/10 * * * *` запускает обновление каждые 10 минут. Обычные запросы читают готовые данные из KV; если каталог отсутствует или его формат устарел, Worker загружает его из NASA. Это сокращает число обращений к внешнему API.

Отсутствующие значения остаются `null`. В интерфейсе они отображаются как «Нет данных» или «Недостаточно данных»; недоступные графики скрываются. При подходящих данных Worker рассчитывает обитаемые зоны по модели Kopparapu et al. (2014) и долю времени, которую орбита проводит внутри них. Модели кратных систем требуют дополнительных данных о компонентах и движении.

### Как считается рейтинг ESI

Текущий рейтинг использует **упрощённый ESI по радиусу и потоку звёздного излучения**, рассчитанный в [`worker/src/esi.js`](worker/src/esi.js):

```text
R = радиус в радиусах Земли
S = поток излучения в единицах земного

dr = (R − 1) / (R + 1)
ds = (S − 1) / (S + 1)
ESI = 1 − sqrt((dr² + ds²) / 2)
```

Для расчёта нужны конечные значения `R > 0` и `S ≥ 0`. Планеты без готового `esi.simple` не входят в топ. Сортировка идёт по убыванию индекса, при равенстве — по ID.

Клиент показывает готовый `planet.esi.simple`, не пересчитывая итог. Две поясняющие шкалы отображают коэффициенты `1 − |dr|` и `1 − |ds|`; они не являются процентными вкладами в ESI. Земля — отдельный локальный эталон с ESI = 1, без места в рейтинге экзопланет.

Функция полного ESI присутствует в исходниках Worker, однако **в текущем каталоге `esi.full = null`**. Автоматического переключения рейтинга на полный ESI сейчас нет.

### Генерация описаний

Worker отправляет параметры объекта и научные инструкции из `worker/src/ai/*.prompt.md` модели `deepseek-v4.1-flash-1017` через AITUNNEL. Ключ `AI_TOKEN` хранится на сервере.

Готовые описания планеты и её звезды сохраняются отдельно в KV без TTL. **Durable Object `DescriptionGenerator`** объединяет одновременные запросы одного объекта и сохраняет результат перед записью в KV, чтобы избежать повторной генерации при задержках или ошибках публикации. Обычное обновление каталога NASA не перезаписывает описания.

В браузере запрос начинается после появления раздела в области просмотра. Успешные ответы кэшируются по ID на время работы страницы, а запоздалый ответ предыдущей планеты не меняет текущий текст. Markdown превращается в DOM-элементы без вставки произвольного HTML; ссылки ограничены HTTP(S). Описание Земли хранится локально и не требует запроса к ИИ.

### HTTP API

Все маршруты принимают `GET`.

| Маршрут | Ответ |
| --- | --- |
| `/preview` | До 50 планет по `esi.simple`, связанные звёзды и `updatedAt` |
| `/full` | Полные каталоги планет и звёзд с `updatedAt` |
| `/planets` | Каталог планет с `updatedAt` |
| `/stars` | Каталог звёзд с `updatedAt` |
| `/desc?id=…` | Описание планеты: `{ "id": "…", "description": "…" }` |

Для `/desc` передаётся точный ID из каталога, закодированный через `URLSearchParams` или `encodeURIComponent`. Подробности API и научные источники приведены в [`worker/README.md`](worker/README.md).

## Локальный запуск

Для работы со всем проектом используйте **Node.js 24+** и npm. Зависимости фронтенда и Worker устанавливаются отдельно.

### Фронтенд

Из корня репозитория:

```bash
npm ci
npm run dev
```

Сайт доступен по адресу `http://localhost:8080/tulahack2026-uno/`. Изменения в `app/` подхватываются сервером разработки автоматически; отдельная команда `watch` не нужна.

```bash
npm run build
npm run preview
```

Сборка попадает в `dist/`, просмотр сборки — `http://localhost:8081/tulahack2026-uno/`. Публичный путь `/tulahack2026-uno/` задан параметром `base` в `vite.config.js`.


### Worker

В отдельном терминале:

```bash
cd worker
npm ci
npx wrangler dev
```

Из папки `worker/`:

```bash
npx wrangler secret put AI_TOKEN
npx wrangler deploy
```

Фронтенд публикуется как статическая сборка `dist/`, Worker развёртывается отдельно в Cloudflare.
