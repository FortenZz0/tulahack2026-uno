# Клиентское приложение

Точка входа — `app/main.js`, подключённая из `app/index.html` как ES module.
Здесь создаётся один `ExoplanetLibrary`, запускается загрузка каталога через
`GetPlanets(library)` и инициализируется звёздный фон через `createStarfield(starfieldOptions)`.
Остальные компоненты пока подключаются автоматически через `import.meta.glob`.
`app/lib` отвечает за работу с API; модуль списка — за отображение планет.

## Звёздный фон

Все настройки задаются в объекте `starfieldOptions` в `app/main.js`.
После изменения достаточно сохранить файл и обновить страницу.
Шейдер и управление отрисовкой находятся в `app/cmp/starfield/script.js`,
стили canvas и резервный градиент — в `app/cmp/starfield/style.sass`.

| Параметр | Значение | Допустимый диапазон и смысл |
| --- | --- | --- |
| `density` | `1` | `0…5`. Относительная плотность: `2` — примерно вдвое больше звёзд, `0` — без звёзд. Это количество на площадь экрана, не группировка в скопления. |
| `brightness` | `1` | `0…3`. Множитель яркости звёзд и их ореолов; дымку не меняет. |
| `twinkleFrequency` | `0.11` | `0…5` Гц. Базовая частота мерцания; у каждой звезды разброс ±25%. `0` останавливает мерцание. |
| `twinkleAmount` | `0.28` | `0…0.5`. Глубина мерцания: `0` — постоянная яркость, `0.5` — от полного затухания до максимума. |
| `driftSpeed` | `1` | `0…10`. Множитель скорости дрейфа. При `1` базовое движение ≈ 0,65 px/с по горизонтали и 0,25 px/с по вертикали, с разной скоростью трёх слоёв. `0` останавливает движение. |
| `starSize` | `1` | `0.25…3`. Множитель размера звёзд и ореолов. |
| `glow` | `0.13` | `0…1`. Интенсивность ореолов; `0` убирает их. |
| `nebulaIntensity` | `1` | `0…3`. Яркость цветной дымки; `0` оставляет тёмный фон. |
| `maxFps` | `30` | `1…60`. Верхний предел частоты кадров фона; фактическая частота зависит от экрана и нагрузки. |
| `maxPixelRatio` | `1.25` | `0.5…2`. Ограничение разрешения canvas относительно CSS-пикселей. Меньше — ниже нагрузка, больше — выше чёткость. |

При `prefers-reduced-motion: reduce` фон статичен. В скрытой вкладке отрисовка
приостанавливается. Без WebGL остаётся CSS-градиент. Настройки проверяются
при запуске; недопустимые значения вызывают `RangeError`.

`createStarfield()` возвращает объект с методом `dispose()`: он освобождает
WebGL-ресурсы, удаляет canvas и обработчики событий. При перезагрузке модуля
Vite его вызывает `main.js`, чтобы фон не запускался повторно поверх старого.
