# Exoplanet Library

Библиотека для получения и анализа данных об экзопланетах из NASA Exoplanet Archive.

Поддерживает: 
* фильтрацию по нескольких параметрам
* сортировку по одному параметру с доп. опцией "по убыванию"/"по возрастанию"
* расчёт показателей потенциальной обитаемости экзопланет (пока ESI и HZ)

### Теория
> ESI - индекс подобия Земле. На данный момент сортируем по нему. Есть полный и упрощенный вариант.

> HZ - зона обитаемости. Это расстояние от Звезды, находясь на котором, 
> на планете может быть жидкая вода. 

## Модель данных

Каждая экзопланета представлена объектом `Planet`.


```javascript 
// lib/planet.js
class Planet {
    name: string | null;

    mass: number | null;
    radius: number | null;
    density: number | null;
    vesc: number | null;
    eqt: number | null;

    flux: number | null;

    star = {
        temperature: number | null,
        luminosity: number | null
    };

    orbit = {
        semiMajorAxis: number | null,
        eccentricity: number | null,
        period: number | null
    };

    esi = {
        full: number | null,
        simple: number | null
    };

    habitableZone = {
        conservative: {
            inner: number | null,
            outer: number | null
        },
        optimistic: {
            inner: number | null,
            outer: number | null
        }
    };
    habitableTimeFraction = {
        conservative: : number | null,
        optimistic: : number | null
    };
}
```



















Основные поля:

- `name` — название планеты.
- `mass` — масса в массах Земли.
- `radius` — радиус в радиусах Земли.
- `density` — плотность в г/см³.
- `vesc` — скорость убегания в км/с. (она же вторая космическая)
- `eqt` — равновесная температура планеты в Кельвинах. Это теоретическая температура поверхности планеты, если бы она была идеальным черным телом, нагреваемым исключительно от своей Звезды.
- `flux` — поток излучения (от Звезды) относительно Земли.

Характеристики звезды (`star`):

- `temperature` — эффективная температура в К.
- `luminosity` — светимость относительно Солнца.

Орбитальные параметры (`orbit`):

- `semiMajorAxis` — большая полуось в а.е.
- `eccentricity` — эксцентриситет орбиты.
- `period` — орбитальный период в днях.

Показатели обитаемости:

- `esi.full` — полный Earth Similarity Index.
- `esi.simple` — упрощённый индекс сходства с Землёй.
- `habitableZone.conservative` — консервативная зона обитаемости.
- `habitableZone.optimistic` — оптимистичная зона обитаемости.
- `habitableTimeFraction.conservative` — доля орбитального периода внутри консервативной зоны.
- `habitableTimeFraction.optimistic` — доля орбитального периода внутри оптимистичной зоны.

Доля означает, что данные в пределе [0; 1]

Каждая зона обитаемости (`habitableZone`)содержит поля `inner` и `outer` — внутреннюю и внешнюю границы в а.е.

Отсутствующие или некорректные исходные значения обозначаются `null`. Производные показатели рассчитываются только при наличии необходимых данных.

## Использование либы

```javascript
import { ExoplanetLibrary } from "./lib/index.js";

const library = new ExoplanetLibrary({
    maxAttempts: 5,
    retryDelay: 1000,
});

library.subscribe("updated", () => {
    console.log("Каталог обновлён:", library.getPlanets());
});

library.subscribe("error", () => {
    console.error("Ошибка загрузки:", library.error);
});

await library.refresh();

const planets = library.getPlanets();
```

## API

### `new ExoplanetLibrary(options)`

Параметры:
- `maxAttempts` — максимальное число запросов, включая первый (по умолчанию 5).
- `retryDelay` — начальная задержка перед повтором в миллисекундах (по умолчанию 1000).

### Методы

- `refresh()` — загружает каталог из NASA и возвращает `Promise<Planet[]>`.
- `getPlanets(options)` — возвращает копию массива планет с возможностью фильтрации, сортировки и пагинации.
- `subscribe(event, callback)` — подписывает на событие и возвращает функцию отписки.

### Поиск и фильтрация

Метод `getPlanets(options)` поддерживает следующие параметры:

- `filters` — числовые фильтры по полям планеты.
- `sort` — сортировка по одному полю.
- `offset` — количество пропускаемых элементов (по умолчанию 0).
- `limit` — максимальное количество возвращаемых элементов.

```javascript
const planets = library.getPlanets({
    filters: {
        radius: { min: 0.5, max: 2 },
        "esi.simple": { min: 0.7 },
    },
    sort: {
        by: "esi.simple",
        order: "desc",
    },
    offset: 0,
    limit: 20,
});
```

Фильтры объединяются по принципу И. Границы `min` и `max` включаются в диапазон.

Поддерживаются вложенные поля через точечную нотацию, например `star.temperature`, `orbit.period` и `habitableTimeFraction.conservative`.

При сортировке отсутствующие значения размещаются в конце списка.

Поиск по названию через параметр `search` пока не реализован.

### События

```javascript
const unsubscribe = library.subscribe("updated", () => {
    console.log(library.getPlanets());
});

// Отмена подписки
unsubscribe();
```

Библиотека поддерживает три события:

- `loading` — начало загрузки каталога.
- `updated` — каталог успешно обновлён.
- `error` — загрузка завершилась ошибкой после всех попыток.

События не передают данные. Для получения актуального каталога необходимо вызвать `getPlanets()`.

### Свойства

- `status` — `idle`, `loading`, `ready` или `error`.
- `lastUpdated` — дата последнего успешного обновления или `null`.
- `error` — последняя ошибка или `null`.


## Расчёты

### Earth Similarity Index

Библиотека рассчитывает два показателя:

- `esi.full` — на основе радиуса, плотности, скорости убегания и равновесной температуры.
- `esi.simple` — на основе радиуса и потока излучения.

Полный ESI рассчитывается только при наличии всех четырёх параметров. Скорость убегания вычисляется из массы и радиуса планеты.

### Зона обитаемости

Границы зоны обитаемости рассчитываются по модели Kopparapu et al. (2014).

Используются два определения:

- Консервативная зона — между пределами runaway greenhouse и maximum greenhouse.
- Оптимистичная зона — между пределами recent Venus и early Mars.

Расчёт выполняется для звёзд с эффективной температурой от 2600 до 7200 К.

При наличии орбитальных параметров дополнительно рассчитывается доля времени, которую планета проводит внутри каждой зоны обитаемости.

Показатели отражают потенциальные условия обитаемости и не подтверждают наличие жизни.

## Обновление данных

Каталог хранится в памяти. Загрузка выполняется только при вызове `refresh()`.

Данные запрашиваются из таблицы `pscomppars` NASA Exoplanet Archive.

При ошибке библиотека повторяет запрос с экспоненциально увеличивающейся задержкой. Если все попытки неудачны, предыдущий каталог сохраняется.

Одновременные вызовы `refresh()` используют одну операцию загрузки.

Поиск, фильтрация и сортировка выполняются локально, без дополнительных запросов к NASA.
